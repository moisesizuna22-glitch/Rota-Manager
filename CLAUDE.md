# CLAUDE.md

## Design Context

See `PRODUCT.md` and `DESIGN.md` for the full strategic and visual spec. Summary:

- **Register:** product · **Platform:** web
- **North Star:** "The Field Terminal" — industrial dispatch chrome (navy base, amber hazard-stripe accents, uppercase tracked type) with a pixel-art RPG leveling layer for gamified address correction.
- **Design principles:** earn progress through real work, not decoration; stay legible outdoors/one-handed; make the compounding value of the shared address database visible; keep the courier flow and admin flow at different paces; lean into grounded RPG texture, never cartoon cuteness.
